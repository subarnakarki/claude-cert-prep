Ten days to exam-ready

An hour or two a day. The days follow the domain weights, so the heaviest domain gets the most time. The last days are for practice runs and fixing weak spots.

  1. day 1

    Map the exam

    Read the domain notes end to end without trying to memorise them. Then run one practice session over all domains to get a baseline.

  2. day 2

    Agentic loops and orchestration

    Domain 1, task statements 1.1–1.4: loop control with stop_reason, coordinator and subagent patterns, and passing context between agents. Then the agentic flashcards.

  3. day 3

    Hooks, handoffs and sessions

    The rest of domain 1: enforcement hooks, escalation, task decomposition and session resumption. Practise agentic until its row turns amber or green.

  4. day 4

    Tool design and MCP

    Domain 2: tool descriptions, structured errors, how tools are split across agents, and MCP server configuration. Then work through the decision rules that mention tools.

  5. day 5

    Claude Code configuration

    Domain 3: the CLAUDE.md hierarchy, rules files, slash commands, skills, plan mode, and non-interactive runs in CI. Do hands-on exercise 2.

  6. day 6

    Prompting and structured output

    Domain 4: explicit criteria, few-shot examples, tool_use with JSON schemas, validation and retry loops, and batch processing. Do hands-on exercise 3.

  7. day 7

    Context and reliability

    Domain 5: keeping case facts intact, escalation triggers, error propagation, exploring large codebases, human review and provenance. Do hands-on exercise 4.

  8. day 8

    Scenarios

    Read all six scenarios. For each one, list the decision rules it's likely to test. Do hands-on exercise 1.

  9. day 9

    Close the gaps

    Follow the overview's next: suggestion until every row is green. Use the "only ones I missed" mode and reread the notes for each miss.

  10. day 10

    Full run, then rest

    One full practice session over all domains and a quick pass through the flashcards. If the overview says "end_turn", book the exam.

Hands-on exercises

The exam guide recommends building these yourself. Each covers several domains, and having built them makes scenario questions far easier to read.

  1. 1. A multi-tool agent with escalation

    agentic · tools_mcp · context

    • Write an agentic loop that continues on "tool_use" and stops on "end_turn".
    • Give it three or four tools with distinct descriptions and structured error responses.
    • Add a hook that blocks a policy violation, such as a refund over the limit, and escalates instead.

  2. 2. Claude Code for a team

    claude_code

    • Set up a project CLAUDE.md, a path-scoped rules file and a shared slash command.
    • Add a skill with its own frontmatter, and configure an MCP server for the project.
    • Run Claude Code non-interactively, the way a CI job would.

  3. 3. A structured extraction pipeline

    prompting · context

    • Extract fields from messy documents with tool_use and a JSON schema, including nullable fields.
    • Validate the output and retry with the specific error when it fails.
    • Process a batch, and send low-confidence items to human review.

  4. 4. A multi-agent research system

    agentic · tools_mcp · context

    • Build a coordinator that delegates to subagents, each with scoped tools.
    • Pass context explicitly and keep source attribution all the way to the final synthesis.
    • Return subagent failures as structured errors the coordinator can act on.
